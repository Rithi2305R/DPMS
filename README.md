 # Department Management System (DPMS)

A web-based Department Management System developed using Python and Django to manage students, staff, attendance, lectures, academic performance, and administrative activities within a department.

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## Features

- Student Registration and Management
- Staff Registration and Management
- Admin Approval System
- Student Attendance Management
- Staff and Class Management
- Lecture Upload and Download
- Academic Performance Management
- Attendance and Performance Reports
- Separate Dashboards for Students, Staff, HOD, and Admin
- User Authentication and Login

## User Roles

### Admin
- Manage students and staff
- Approve registrations
- Manage department information

### HOD
- Monitor student attendance and academic performance
- View reports
- Manage department activities

### Staff
- Manage assigned students
- Record attendance
- Upload lecture materials
- Manage academic information

### Student
- View attendance
- View academic performance
- Download lecture materials
- Access student dashboard

## Project Structure

The project is developed using the Django framework and follows a modular structure for managing different department activities.

## Database

SQLite is used as the database for storing application data.

## Purpose

The main purpose of this project is to provide a centralized platform for managing department-related academic and administrative activities efficiently.
